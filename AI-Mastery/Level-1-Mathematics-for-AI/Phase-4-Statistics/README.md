# Phase 4 — Statistics for Artificial Intelligence

## Overview
Statistics is the mathematical discipline of collecting, analyzing, interpreting, and presenting data. In Artificial Intelligence and Machine Learning, statistics provides the core toolkit for data exploration, feature analysis, hypothesis testing, model evaluation, A/B testing, and quantifying confidence in AI predictions.

## Concepts Covered
- Descriptive Statistics: Mean, Median, Mode, Variance, Standard Deviation, Range, IQR
- Shape Parameters: Skewness, Kurtosis, and Normalizing Transformations
- Statistical Distributions: Gaussian $Z$-Scores, Student's $t$, Chi-Square $\chi^2$, F-Distribution
- Inferential Statistics: Population Parameters vs Sample Statistics
- Sampling Methods, Sampling Bias, and Sampling Distributions
- Central Limit Theorem (CLT) & Standard Error (SE)
- Confidence Intervals (Z-Intervals and t-Intervals)
- Hypothesis Testing Framework: Null $H_0$ and Alternative $H_a$ Hypotheses
- $p$-values, Significance Level $\alpha$, Critical Values, Test Statistics
- Type I Errors (False Positive) & Type II Errors (False Negative, Power $1-\beta$)
- Statistical Tests: $Z$-Test, $t$-Tests (One-sample, Two-sample, Paired), Chi-Square $\chi^2$ Test
- Applied AI Statistics: A/B Testing, Feature Selection, Statsmodels & SciPy in Python

## AI Connections
- **Central Limit Theorem**: Guarantees sample averages converge to Normal distributions regardless of population shape.
- **Hypothesis Testing & A/B Testing**: Validates whether AI model updates (e.g. Model B vs Model A) provide statistically significant performance gains.
- **$p$-values & Feature Selection**: Identifies statistically significant input features ($p < 0.05$) in ANOVA and regression modeling.
- **Confidence Intervals**: Computes error margins around model accuracy estimates.
