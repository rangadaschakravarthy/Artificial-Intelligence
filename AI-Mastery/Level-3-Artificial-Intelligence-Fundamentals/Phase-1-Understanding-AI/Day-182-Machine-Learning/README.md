# Day 182 — Machine Learning

## Learning Objectives
- Understand Machine Learning as a paradigm shift from hand-coded rules to data-driven learning algorithms.
- Distinguish between Supervised, Unsupervised, and Reinforcement Learning paradigms.
- Contrast Symbolic AI with Statistical Machine Learning.

## Prerequisites
- Level 2: Data Science Foundations
- Day 181: Symbolic AI

## Topics Covered
- Machine Learning Definition (Arthur Samuel 1959 / Tom Mitchell 1997)
- Mitchell's ML Definition: $P$ improves with $E$ with respect to $T$
- Paradigm Shift: Rules + Data $\to$ Output (Traditional) vs Data + Output $\to$ Rules (ML)
- ML Subfields: Supervised, Unsupervised, Reinforcement Learning
- Why ML replaced pure Symbolic AI for perceptual tasks
