# Practice Exercises — Scalars and Vectors

## Level 1 — Basic Understanding
1. Is wind speed a scalar or vector? What about wind velocity?
2. Write the vector $\mathbf{x} = [2, -5, 0]$ as a column vector.
3. What is the dimension of the vector $\mathbf{v} = [1.2, 0.0, -3.4, 5.1, 9.0]^T$?
4. Represent a car with top speed 220 km/h, 4 doors, and engine power 300 hp as a vector.
5. What does $\mathbb{R}^3$ mean?

## Level 2 — Calculation
1. Given scalar $c = 3$ and vector $\mathbf{v} = [2, 4]^T$, compute $c\mathbf{v}$.
2. Identify the component $v_3$ of vector $\mathbf{v} = [10, 20, 30, 40]^T$.
3. If vector $\mathbf{a} \in \mathbb{R}^m$ and vector $\mathbf{b} \in \mathbb{R}^n$ have equal dimensions, what can we say about $m$ and $n$?
4. Convert row vector $[1, 2, 3]$ to column vector transpose format.
5. If a dataset has 50 columns, what is the dimension of each row's feature vector?

## Level 3 — Conceptual
1. Geometric interpretation of vector scaling by $c = -2$.
2. Why is a 1D NumPy array called a 1D tensor in PyTorch/TensorFlow?
3. Explain the difference between a zero vector and a scalar zero.
4. How does adding a constant feature (e.g. 1.0) change vector dimension?
5. Can a vector have complex numbers in standard AI applications?

## Level 4 — AI/ML Application
1. Construct a 5-dimensional feature vector for a customer churn model.
2. In NLP, if vocabulary size is 10,000, what is the dimension of a one-hot encoded vector?
3. Explain how a 2D image pixel grid converts into a 1D flattened feature vector.

## Level 5 — Interview Questions
1. What is the physical and mathematical difference between a point and a vector in $\mathbb{R}^n$?
2. Why do deep learning frameworks prefer column vector conventions for inputs?
3. How does vector sparsity (many zeros) affect storage and computation?
4. Explain how sparse vectors differ from dense embeddings.
5. What happens to feature vectors when features are measured on vastly different scales?
