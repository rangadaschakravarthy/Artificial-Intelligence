# Day 176 — Rational Agents

## Learning Objectives
- Understand rationality, expected utility maximization, and decision theory.
- Distinguish between a Rational Agent and an Omniscient Agent.
- Formulate expected utility calculations under environmental uncertainty.

## Prerequisites
- Day 175: Intelligent Agents
- Level 1 Probability: Expected Value

## Topics Covered
- Definition of Rationality: Doing the right thing (maximizing expected performance)
- The 4 Factors of Rationality: Performance measure, Percept history, Knowledge, Action space
- Rationality vs Omniscient (Rationality maximizes *expected* outcome, not guaranteed outcome)
- Information Gathering and Exploration vs Exploitation
- Bounded Rationality (Herbert Simon's limits on computational capacity)

## Completion Checklist
- [ ] I can define a rational agent mathematically.
- [ ] I understand why rationality does not imply perfection.
- [ ] I can calculate Expected Utility for simple decision trees.
