# Examples — Partial Derivatives

## Example 1 — Very Easy
Partial w.r.t $x$: $f(x, y) = x^2 + 3xy + y^2 \implies f_x = 2x + 3y$.

## Example 2 — Beginner
Partial w.r.t $y$: $f(x, y) = x^2 + 3xy + y^2 \implies f_y = 3x + 2y$.

## Example 3 — Intermediate
Evaluating at Point: At $(x=1, y=2)$, $f_x(1, 2) = 2(1) + 3(2) = 8$.

## Example 4 — AI/ML Example
MSE Loss Partials: $L(w, b) = (w x + b - y)^2 \implies \frac{\partial L}{\partial w} = 2(w x + b - y)x, \frac{\partial L}{\partial b} = 2(w x + b - y)$.
