# Day 142 — Seaborn Introduction

## Learning Objectives
- Understand Seaborn's high-level statistical plotting philosophy built on top of Matplotlib.
- Master Seaborn themes, color palettes, and context scaling.
- Seamlessly integrate Seaborn with Pandas DataFrames.

## Prerequisites
- Day 108: DataFrames
- Day 134: Matplotlib Basics

## Topics Covered
- Why Seaborn? High-level API vs raw Matplotlib
- DataFrame integration (`data=df`, `x='col'`, `y='col'`, `hue='group'`)
- Built-in themes (`sns.set_theme(style='darkgrid'|'whitegrid'|'ticks')`)
- Color Palettes (`sns.color_palette()`, `'deep'`, `'muted'`, `'rocket'`, `'viridis'`)
- Scaling contexts (`sns.set_context('paper'|'notebook'|'talk'|'poster')`)

## Why This Matters
Seaborn allows data scientists to write beautiful statistical graphics in 1 line of code that would require 20 lines of Matplotlib.

## Practical Work
- Generate statistical plots using Seaborn themes and custom color palettes.
