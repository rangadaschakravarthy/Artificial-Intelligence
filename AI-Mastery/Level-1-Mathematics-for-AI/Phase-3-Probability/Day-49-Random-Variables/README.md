# Day 49 — Random Variables

## Learning Objectives
- Understand random variables as functions mapping outcomes from sample space $\Omega$ to real numbers $\mathbb{R}$.
- Distinguish between discrete and continuous random variables.
- Master notation $X, Y, Z$ vs specific realized values $x, y, z$.
- Map features and target variables in machine learning to random variables.

## Prerequisites
- Days 44–48 Probability basics and set theory.

## Topics Covered
1. Mathematical Definition of a Random Variable $X: \Omega 	o \mathbb{R}$
2. Discrete vs Continuous Random Variables
3. Support / Range of a Random Variable
4. Random Variables in Machine Learning Datasets
5. Transformations of Random Variables

## Why This Matters for AI
Every column in a tabular dataset, pixel intensity in an image, or token embedding in NLP is modeled mathematically as a random variable. Probability distributions over random variables govern ML training and predictions.
