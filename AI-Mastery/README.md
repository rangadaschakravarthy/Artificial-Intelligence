# AI Mastery — Comprehensive Curriculum for Artificial Intelligence & Machine Learning

Welcome to **AI Mastery**, the ultimate, beginner-friendly, production-grade learning repository for Artificial Intelligence, Machine Learning, Deep Learning, Natural Language Processing, Computer Vision, and Generative AI.

---

## 🗺️ Curriculum Structure Overview

This repository is structured into progressive levels that take you from fundamental mathematical principles to state-of-the-art AI architecture design and engineering.

### 📚 Level 1 — Mathematics for Artificial Intelligence
**Status**: 100% Complete (85 Continuous Days + Capstone & Revision Modules)

- **Phase 1: Linear Algebra** (Days 1–25)
  - Vectors, Matrices, Matrix Multiplications, Determinants, Inverses, Eigenvalues/Eigenvectors, SVD, PCA.
- **Phase 2: Calculus** (Days 26–43)
  - Derivatives, Partial Derivatives, Gradients, Jacobians, Optimization, Loss Functions, Gradient Descent, Backpropagation.
- **Phase 3: Probability** (Days 44–62)
  - Random Variables, Bayes' Theorem, Discrete & Continuous Distributions, Joint/Marginal Probability, Naive Bayes.
- **Phase 4: Statistics** (Days 63–85)
  - Descriptive Stats, Sampling Distributions, CLT, Point/Interval Estimation, Hypothesis Testing, ANOVA, Chi-Square, A/B Testing.
- **Specialized Modules**:
  - `AI-Connections.md`: Detailed map connecting math topics to AI architectures.
  - `Formula-Sheet.md`: Comprehensive cheat-sheet of every formula.
  - `Interview-Questions.md`: Top 100 mathematical AI interview questions with answers.
  - `Final-Revision/`: 7 dedicated revision guides, formula reviews, concept maps, and full mock tests with solutions.
  - `Capstone-Mathematics-for-AI/`: End-to-end mathematical implementation project building ML algorithms from pure scratch.

## 🎯 How to Use This Repository

Every single day directory (`Day-X-...`) contains 6 core educational files:
1. `README.md` — Daily Learning Plan & Objectives
2. `theory.md` — 14 Deeply Detailed Educational Sections
3. `examples.md` — 5 Multi-Level Worked Numerical & AI Examples
4. `practice.md` — 23 Practice Questions Across 5 Skill Levels
5. `solution.md` — Step-by-Step Mathematical Solutions
6. `code.py` — Runnable Python Scripts (Manual + NumPy/SciPy/PyTorch)
