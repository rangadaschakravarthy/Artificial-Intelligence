# Day 156 — Encoding

## Learning Objectives
- Master the fundamental concepts and mathematics of categorical feature encoding.
- Distinguish between Nominal Encoding (One-Hot, Binary) and Ordinal Encoding.
- Evaluate the trade-offs of different encoding strategies on model performance.

## Prerequisites
- Day 155: Categorical and Numerical Features

## Topics Covered
- Why Categorical Encoding is Required (ML algorithms operate on $\mathbb{R}^d$ vector spaces)
- Nominal vs Ordinal Categorical Variables
- Overview of Encoding Methods: Label Encoding, Ordinal Encoding, One-Hot Encoding, Target Encoding, Frequency Encoding
- Vector representation & Orthogonality of One-Hot Vectors
- The Curse of Dimensionality resulting from high-cardinality encoding

## Practical Work
- Build a custom Python class implementing Frequency Encoding for high-cardinality features.
