# Examples — Linear Independence

## Example 1 — Very Easy
Standard Basis: $\mathbf{e}_1 = [1, 0]^T, \mathbf{e}_2 = [0, 1]^T$ are linearly independent.

## Example 2 — Beginner
Collinear Vectors: $\mathbf{u} = [2, 5]^T, \mathbf{v} = [-4, -10]^T$ are dependent ($\mathbf{v} = -2\mathbf{u}$).

## Example 3 — Intermediate
3D Independent Set: $\mathbf{a} = [1, 0, 0]^T, \mathbf{b} = [1, 1, 0]^T, \mathbf{c} = [1, 1, 1]^T \implies \det = 1 \neq 0$ (Independent!).

## Example 4 — AI/ML Example
Overcomplete Set: 4 vectors in $\mathbb{R}^3$ (Always linearly dependent!).

## Example 5 — Real-World Interpretation
Dummy Variable Trap: Creating 3 one-hot columns for 3 categories without dropping one creates linear dependence with bias 1 vector.
