# Day 141 — Customizing Matplotlib

## Learning Objectives
- Apply publication-grade styling, custom color palettes, and typography to Matplotlib charts.
- Master Matplotlib configuration files (`plt.rcParams`) and built-in style sheets (`plt.style.use()`).
- Annotate specific data points with arrows and custom text callouts.

## Prerequisites
- Days 134–140 (Matplotlib Core)

## Topics Covered
- Global parameter configuration with `plt.rcParams`
- Matplotlib built-in styles (`'seaborn-v0_8'`, `'ggplot'`, `'dark_background'`)
- Custom text annotations and arrows (`ax.annotate()`)
- Custom color maps and hex color palettes
- Removing spines and customizing tick locators/formatters

## Why This Matters
Default plots look amateurish. Customizing typography, spines, colors, and annotations transforms standard charts into publication-ready graphics.

## Practical Work
- Apply a custom dark-mode style theme with annotated peak points.
