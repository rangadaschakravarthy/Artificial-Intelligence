# Day 143 — Seaborn Categorical Plots

## Learning Objectives
- Visualize categorical feature distributions using `catplot()`, `boxplot()`, `violinplot()`, `boxenplot()`, `barplot()`, and `countplot()`.
- Compare Violin plots vs Box plots for multimodal distribution detection.
- Master strip plots and swarm plots for individual observation overlay.

## Prerequisites
- Day 139: Box Plots
- Day 142: Seaborn Introduction

## Topics Covered
- Categorical plots overview (`sns.catplot()`)
- Categorical counts: `sns.countplot()`
- Categorical summaries: `sns.barplot()`, `sns.pointplot()`
- Categorical distributions: `sns.boxplot()`, `sns.violinplot()`, `sns.boxenplot()`
- Categorical scatter overlays: `sns.stripplot()`, `sns.swarmplot()`
- Combining Violin plots with inner box plots or swarm points

## Why This Matters
Categorical variables are abundant in business data (e.g. tier, region, segment). Seaborn categorical plots reveal sub-group variation immediately.

## Practical Work
- Plot a Violin plot with inner quartiles comparing salary distributions by department.
