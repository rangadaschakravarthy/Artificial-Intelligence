# Day 46 — Rules of Probability

## Learning Objectives
- Master the Addition Rule for general and mutually exclusive events.
- Master the Multiplication Rule for independent and dependent events.
- Apply the Complement Rule $P(A^c) = 1 - P(A)$ for efficient problem solving.
- Calculate joint and marginal probabilities in AI datasets.

## Prerequisites
- Day 44 Introduction to Probability.
- Day 45 Sample Spaces and Events.

## Topics Covered
1. The Complement Rule
2. The Addition Rule (Inclusion-Exclusion Principle)
3. The Multiplication Rule
4. Joint Probability $P(A, B)$
5. Probability Rules in Classification evaluation

## Why This Matters for AI
Evaluating machine learning error rates, false positive rates, and ensemble predictions relies directly on probability rules. Calculating "at least one failure" via complementation is a staple of AI system safety.
