# Level 2 — Data Science Foundations

Welcome to **Level 2: Data Science Foundations**, the second stage of the **AI-Mastery** curriculum.

This course transitions from Level 1 mathematical theory into practical numerical computing, data manipulation, visualization, data cleaning, exploratory data analysis, and machine learning dataset preprocessing.

---

## 🗺️ Curriculum Progression Roadmap

```
Level 1: Mathematics for AI
          │
          ▼
Level 2: Data Science Foundations
  ├── Phase 1: NumPy Numerical Computing (Days 86–105)
  ├── Phase 2: Pandas Data Manipulation & Cleaning (Days 106–132)
  ├── Phase 3: Data Visualization (Matplotlib, Seaborn, Plotly) (Days 133–152)
  └── Phase 4: Data Preprocessing & ML Readiness (Days 153–172)
          │
          ▼
Level 3: Machine Learning
```

---

## 📚 Curriculum Structure

- **Phase 1 — NumPy (Days 86–105)**: Continuous day numbering covering `ndarray`, multidimensional shapes, broadcasting, vectorization, and linear algebra.
- **Phase 2 — Pandas (Days 106–132)**: Series, DataFrames, dataset inspection, missing data imputation, deduplication, GroupBy aggregations, merging, joins, and time series.
- **Phase 3 — Data Visualization (Days 133–152)**: Matplotlib Object-Oriented interface, Seaborn statistical graphics, Plotly interactive HTML charts, and data storytelling.
- **Phase 4 — Data Preprocessing (Days 153–172)**: One-Hot and Ordinal encoding, Z-score standardization, Min-Max normalization, Winsorization outlier capping, feature selection, and data leakage prevention.
- **Capstone & Revision**: Standalone reference sheets, revision guides, practice tests, 3 capstone projects, and a final data science project preparing ML-ready arrays.
