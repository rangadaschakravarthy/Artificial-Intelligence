# Day 103 — NumPy for Machine Learning

## Learning Objectives
- Build core Machine Learning operations from scratch using pure NumPy.
- Implement forward propagation, activation functions (ReLU, Sigmoid, Softmax), and loss functions (MSE, Cross-Entropy).
- Implement Gradient Descent optimization weight updates.

## Prerequisites
- Level 1: Calculus (Gradients, Optimization)
- Day 96: Array Operations
- Day 102: Linear Algebra with NumPy

## Topics Covered
1. Representing Datasets as Feature Matrices $X$ and Target Vectors $y$
2. Vectorized Activation Functions (Sigmoid, ReLU, Softmax)
3. Vectorized Loss Functions (MSE, Binary Cross-Entropy)
4. Vectorized Gradient Computation and Weight Updates
5. Building a Linear Regression Model from scratch in NumPy

## Why This Matters
Implementing machine learning primitives in raw NumPy removes "black-box" abstractions, providing deep intuition for PyTorch and TensorFlow internal mechanics.

## Real-World Usage
Understanding how ML frameworks compute gradients, update model weights, and track training loss histories.
