# Day 8 — Matrix Operations

## Learning Objectives
- Perform matrix addition and subtraction on matrices of matching dimensions
- Perform scalar-matrix multiplication
- Understand element-wise (Hadamard) matrix multiplication
- Understand matrix broadcasting rules in NumPy

## Prerequisites
Day 7 — Matrices, Day 3 — Vector Operations

## Topics Covered
- Matrix Addition and Subtraction
- Scalar Multiplication
- Element-wise (Hadamard) Matrix Product $\mathbf{A} \odot \mathbf{B}$
- Properties of Matrix Addition (Commutative, Associative)
- Broadcasting vectors over matrices

## Why This Matters for AI
Element-wise operations and broadcasting allow AI models to add bias vectors to entire batches of samples simultaneously, apply activation functions (ReLU, Sigmoid), and apply masks.
