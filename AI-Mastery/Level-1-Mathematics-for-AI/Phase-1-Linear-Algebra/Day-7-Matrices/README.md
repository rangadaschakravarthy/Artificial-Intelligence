# Day 7 — Matrices

## Learning Objectives
- Understand matrices as 2D grids of numbers structured in rows and columns
- Master matrix shape/dimensions notation ($m \times n$)
- Identify key matrix types (Square, Diagonal, Symmetric, Zero, Triangular)
- Represent datasets and linear transformations as matrices

## Prerequisites
Day 2 — Scalars and Vectors

## Topics Covered
- Matrix Definition and Shape ($m$ rows, $n$ columns)
- Matrix indexing notation ($A_{i,j}$)
- Special Matrices: Square, Zero, Diagonal, Symmetric, Upper/Lower Triangular
- Matrices as Data Tables (Samples $\times$ Features)
- Matrices as Linear Transformation Operators

## Why This Matters for AI
Matrices are the foundational data structure of AI models. A dataset is a matrix (rows=samples, cols=features); neural network layer weights are stored as matrices.
