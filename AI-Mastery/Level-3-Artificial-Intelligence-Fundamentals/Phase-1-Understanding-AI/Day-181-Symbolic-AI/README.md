# Day 181 — Symbolic AI

## Learning Objectives
- Understand Symbolic AI (GOFAI - Good Old-Fashioned AI) based on explicit rules and symbols.
- Learn Physical Symbol System Hypothesis (Newell & Simon).
- Contrast Symbolic AI with statistical connectionist AI.

## Prerequisites
- Day 173: Introduction to AI

## Topics Covered
- Symbolic AI / Classical AI / GOFAI definition
- Physical Symbol System Hypothesis
- Knowledge Bases, Knowledge Representation, and Inference Engines
- Strengths: Explainability, deterministic logic, zero data requirement for hand-coded rules
- Weaknesses: Knowledge Acquisition Bottleneck, brittleness, failure on perceptual noisy data (Vision/Speech)

## Difficulty
Intermediate
