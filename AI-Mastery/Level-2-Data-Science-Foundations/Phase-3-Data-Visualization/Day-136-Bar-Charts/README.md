# Day 136 — Bar Charts

## Learning Objectives
- Compare discrete categorical quantities using vertical (`ax.bar()`) and horizontal (`ax.barh()`) bar charts.
- Build grouped (clustered) and stacked bar charts for multi-category analysis.
- Annotate bar containers with exact data value labels.

## Prerequisites
- Day 134: Matplotlib Basics

## Topics Covered
- Vertical bar charts (`ax.bar()`) vs Horizontal bar charts (`ax.barh()`)
- Clustered / Grouped bar charts (shifting x positions)
- Stacked bar charts (`bottom` / `left` parameters)
- Labeling bar values using `ax.bar_label()`
- Sorting categorical bars by value magnitude for clarity

## Why This Matters
Bar charts are the workhorse of categorical business metrics (e.g. sales by region, market share by brand).

## Practical Work
- Construct a grouped bar chart comparing Q1 vs Q2 sales across 4 regional branches.
