# Day 43 — Calculus AI Mini-Project

## Learning Objectives
- Build a complete Multi-Layer Neural Network library from scratch in pure NumPy using Calculus
- Implement explicit Forward Pass, Loss Computation, Backpropagation, and SGD Gradient Updates
- Train the neural network to solve non-linearly separable classification problems (XOR & Concentric Circles)
- Verify mathematical gradients and plot training loss convergence curves

## Prerequisites
Days 26-42 Calculus Phase

## Topics Covered
- Project Architecture: Building a Pure NumPy Deep Learning Framework
- Step 1: Dense Linear Layer ($Z = X W^T + b$)
- Step 2: Activation Layers (Sigmoid, ReLU) and their derivatives
- Step 3: Loss Functions (Binary Cross-Entropy) and derivative
- Step 4: Full Backpropagation Engine (Chain Rule Delta Propagation)
- Step 5: Mini-Batch SGD Optimizer
- Training on non-linear XOR and Circle datasets

## Why This Matters for AI
This capstone mini-project completes Phase 2, proving that you can build and train deep neural networks using pure calculus and matrix algebra without PyTorch or TensorFlow.
