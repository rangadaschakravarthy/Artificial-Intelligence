# Day 133 — Introduction to Data Visualization

## Learning Objectives
- Understand the role of visualization in exploratory data analysis and data storytelling.
- Distinguish between Matplotlib, Seaborn, and Plotly ecosystem strengths.
- Learn visual encoding principles (color, scale, axes, chart selection).

## Prerequisites
- Days 106–132 (Pandas Foundations)

## Topics Covered
- Why Data Visualization Matters (Anscombe's Quartet & Datasaurus Dozen)
- Python Visualization Ecosystem: Matplotlib vs Seaborn vs Plotly
- Visual Encoding: Channels (Position, Color, Size, Shape)
- Chart Types for Variable Cardinality (Continuous, Categorical, Time-Series)
- Common Pitfalls: Misleading axes, chartjunk, and low-contrast palettes

## Why This Matters
Raw numbers fail to convey patterns immediately. Visual representations convert complex tabular data into intuitive cognitive insights.

## Real-World Usage
Creating executive dashboards and diagnostic plots for machine learning model evaluation.
