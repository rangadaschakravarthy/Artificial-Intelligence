# Day 149 — Visualization Selection

## Learning Objectives
- Select the optimal chart type based on data variable types, cardinality, and analytical objectives.
- Apply the Data Visualization Decision Tree (Comparison, Distribution, Relationship, Composition).
- Avoid common visualization anti-patterns and misleading charts.

## Prerequisites
- Days 133–148 (Data Visualization Fundamentals)

## Topics Covered
- The 4 Primary Visualization Goals: Comparison, Distribution, Relationship, Composition
- Chart Selection Matrix (Continuous vs Categorical, Single vs Multi-Variable)
- When NOT to use specific charts (e.g. 3D pie charts, truncated y-axes)
- Matching charts to business questions
- Designing accessible plots (colorblind-safe palettes)

## Why This Matters
Choosing the wrong chart type confuses users, distorts data signals, and leads to incorrect business decisions.

## Practical Work
- Map 5 distinct business analysis questions to their optimal chart types using the Selection Framework.

## Difficulty
Intermediate
