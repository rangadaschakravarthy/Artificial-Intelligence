# Day 50 — Discrete Random Variables

## Learning Objectives
- Master Probability Mass Functions (PMF) $P(X = x) = p(x)$.
- Master Cumulative Distribution Functions (CDF) $F(x) = P(X \le x)$.
- Verify PMF validity requirements $\sum p(x) = 1$ and $p(x) \ge 0$.
- Compute discrete PMF and CDF in Python.

## Prerequisites
- Day 49 Random Variables.

## Topics Covered
1. Probability Mass Function (PMF)
2. Cumulative Distribution Function (CDF) for Discrete RVs
3. Properties of PMF and CDF
4. Expectation and Variance of Discrete RVs
5. Python PMF/CDF modeling with NumPy and SciPy

## Why This Matters for AI
Classification targets, token frequencies in NLP, count data in analytics, and discrete decision actions in Reinforcement Learning are governed by discrete PMFs and CDFs.
