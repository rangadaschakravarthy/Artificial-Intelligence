# Practice Problems — Rules of Probability

## Level 1: Basic Concept Checks
1. State the formula for $P(A \cup B)$ for mutually exclusive events.
2. If $P(A) = 0.42$, what is $P(A^c)$?
3. What is $P(A \cap B)$ if $A$ and $B$ are independent?
4. True or False: $P(A \cup B)$ can be greater than $P(A) + P(B)$.
5. Write the general Multiplication Rule formula.

## Level 2: Direct Calculations
6. If $P(A) = 0.5$, $P(B) = 0.4$, $P(A \cap B) = 0.2$, find $P(A \cup B)$.
7. If $P(A) = 0.7$, $P(B) = 0.3$, and $A, B$ are disjoint, find $P(A \cup B)$.
8. Three independent coin tosses. Find $P(	ext{At least 1 Heads})$.
9. Draw 2 cards from a standard deck with replacement. Find $P(	ext{Both Kings})$.
10. Draw 2 cards from a standard deck without replacement. Find $P(	ext{Both Kings})$.

## Level 3: Conceptual & Multi-Step Problems
11. Show that $P(A \cap B) \ge P(A) + P(B) - 1$ (Bonferroni's Inequality).
12. A system has 4 independent components with failure probabilities 0.05 each. Find probability system operates (all 4 work).
13. If $P(A) = 0.6$ and $P(B) = 0.5$, what is the minimum possible value of $P(A \cap B)$?
14. What is the maximum possible value of $P(A \cap B)$ for the numbers in Q13?
15. If $P(A^c \cap B^c) = 0.2$, find $P(A \cup B)$.

## Level 4: AI & ML Applications
16. A server pipeline has 3 sequential AI microservices with uptime probabilities 0.99, 0.98, and 0.95. Calculate overall pipeline uptime.
17. An anomaly detection ensemble of 5 independent models flags alert if majority (at least 3) vote positive. If individual model false positive rate is 0.10, compute ensemble false positive rate.
18. In a recommender system, $P(	ext{Click}) = 0.10$ and $P(	ext{Buy} | 	ext{Click}) = 0.25$. Calculate $P(	ext{Click AND Buy})$.
19. Compute the reliability of a dual-redundant server pair where each server has uptime 0.99 (system up if at least one works).
20. In an NLP filter, $P(	ext{Spam}) = 0.20$. If 5 independent emails arrive, what is the probability that at least one is spam?

## Level 5: Interview Questions
21. Derive Bonferroni's Inequality $P(A \cap B) \ge P(A) + P(B) - 1$.
22. Explain how Condorcet's Jury Theorem relates to ensemble learning in machine learning.
23. Why is drawing without replacement dependent, while drawing with replacement is independent?
