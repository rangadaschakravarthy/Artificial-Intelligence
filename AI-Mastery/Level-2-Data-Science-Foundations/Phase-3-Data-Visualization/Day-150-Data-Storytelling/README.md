# Day 150 — Data Storytelling

## Learning Objectives
- Transform raw visual charts into narrative data stories.
- Apply clutter-reduction principles (Edward Tufte's Data-Ink Ratio).
- Use color strategically to direct audience attention to key insights.

## Prerequisites
- Days 133–149 (Data Visualization Phase)

## Topics Covered
- Data Storytelling Framework: Context + Visual + Narrative
- Edward Tufte's Data-to-Ink Ratio ($	ext{Data Ink} / 	ext{Total Ink}$)
- Strategic Color Choice: Graying out non-essential data and highlighting key data points
- Writing action-oriented chart titles (e.g., "Revenue Grew 25% in Q4" vs "Quarterly Revenue")
- Eliminating chartjunk (heavy borders, unnecessary 3D effects, redundant legends)

## Why This Matters
Charts alone do not drive decisions. Data storytelling translates visual patterns into compelling business narratives.

## Practical Work
- Redesign a cluttered default chart into a clean, narrative-focused story graphic.

## Difficulty
Intermediate
