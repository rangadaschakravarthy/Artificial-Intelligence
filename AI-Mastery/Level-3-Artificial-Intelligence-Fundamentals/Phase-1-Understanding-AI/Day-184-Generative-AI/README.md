# Day 184 — Generative AI

## Learning Objectives
- Understand Generative AI as a capability class within Deep Learning focused on creating new content.
- Contrast Discriminative Models ($P(Y \mid X)$) with Generative Models ($P(X)$ or $P(X, Y)$).
- Examine modern Generative AI modalities (Text, Image, Audio, Code, Multimodal).

## Prerequisites
- Day 183: Deep Learning

## Topics Covered
- Generative AI Definition (AI systems capable of generating novel synthetic content)
- Discriminative vs Generative Modeling:
  - **Discriminative**: Classifies or predicts labels $P(Y \mid X)$ (e.g. "Is this image a cat?")
  - **Generative**: Models feature distribution $P(X)$ to sample novel data instances (e.g. "Generate a new image of a cat")
- Key Generative Architectures: GANs, VAEs, Diffusion Models, Transformer Large Language Models (LLMs)
- Multimodal Generation (Text-to-Image, Text-to-Video, Speech-to-Code)
