# Day 186 — AI vs Automation

## Learning Objectives
- Differentiate between Rule-Based Automation, Robotic Process Automation (RPA), and AI Decision Systems.
- Understand the spectrum from basic script execution to adaptive intelligence.
- Analyze enterprise automation architectures.

## Prerequisites
- Day 173: Introduction to AI

## Topics Covered
- Automation Definition: Repetitive execution of fixed, deterministic workflows
- Robotic Process Automation (RPA) vs Intelligent Automation (IA)
- Key Differences: Adaptability, handling unstructured data, dealing with uncertainty
- Spectrum: Cron Job -> Script Automation -> Rule Engine -> Statistical AI -> Adaptive ML Agent

## Difficulty
Beginner / Intermediate
