# Day 139 — Box Plots

## Learning Objectives
- Visualize 5-number statistical summaries (Min, Q1, Median, Q3, Max) and outliers using `ax.boxplot()`.
- Identify interquartile range (IQR) and extreme outlier points.
- Compare distributions across multiple categorical subgroups.

## Prerequisites
- Day 134: Matplotlib Basics
- Day 115: Outliers & IQR (Level 1 Statistics)

## Topics Covered
- Anatomy of a Box Plot (Median line, Q1/Q3 box, $1.5 	imes 	ext{IQR}$ whiskers, fliers)
- `ax.boxplot()` parameters: `notch`, `vert`, `patch_artist`, `showmeans`
- Customizing box fill colors and outlier flier markers
- Comparative side-by-side boxplots for categorical features

## Why This Matters
Box plots provide the standard visual method for identifying statistical outliers and comparing group distribution spreads.
