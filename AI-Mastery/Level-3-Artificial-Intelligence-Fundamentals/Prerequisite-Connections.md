# Prerequisite Connections: Level 1 & 2 to Level 3

## Connection to Level 1 (Mathematics for AI)
- **Linear Algebra**: State space vectors, transformation matrices, and graph adjacency matrix operations.
- **Calculus**: Optimization objective functions and gradient analogies in heuristic evaluation.
- **Probability & Statistics**: Stochastic transition models $P(s' | s, a)$, Maximum Expected Utility (MEU), and belief state spaces.

## Connection to Level 2 (Data Science Foundations)
- **NumPy**: Matrix representation of game boards, 2D grid mazes, and vector state transformations.
- **Pandas**: Benchmarking search performance metrics (nodes expanded, runtime, memory footprint) across algorithm configurations.
- **Data Preprocessing & Structure**: Efficient hashing, indexing, and immutability techniques for state dictionary representations.
