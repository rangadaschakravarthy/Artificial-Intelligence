# Day 63 Worked Examples: Introduction to Statistics

## Example 1: Very Easy — Sample Mean
Dataset: [2, 4, 6, 8, 10]. Mean = 30 / 5 = 6.

## Example 2: Beginner — Population vs Sample
100,000 hospital records (Population). 500 sampled records (Sample n=500).

## Example 3: Intermediate — Estimating Click-Through Rate
Sample size n = 5,000 users. Clicks = 250.
Sample CTR = 250 / 5000 = 0.05 (5%).

## Example 4: AI Focus — Training Set as Sample
A LLM trained on 1 Trillion tokens is a sample of all human language (population).

## Example 5: Real-World AI — Model Drift Detection
If production input data mean μ_prod shifts significantly from training data mean μ_train, model drift is detected.
