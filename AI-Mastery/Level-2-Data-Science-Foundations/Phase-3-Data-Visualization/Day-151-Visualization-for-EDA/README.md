# Day 151 — Visualization for EDA

## Learning Objectives
- Integrate graphical visualization directly into exploratory data analysis pipelines.
- Automate distribution, correlation, and missing data visual diagnostics.
- Visualize missing data patterns using `missingno`.

## Prerequisites
- Day 130: Exploratory Data Analysis
- Days 133–150 (Data Visualization)

## Topics Covered
- Visual EDA Framework (1D Distributions -> 2D Relationships -> Multi-Dimensional Grids)
- Visualizing missing data matrix patterns
- Automated visual EDA functions
- Detecting outliers and skewness visually
- Visual feature inspection before Machine Learning modeling

## Why This Matters
Visual EDA catches data anomalies (multimodal distributions, extreme outliers, non-linear relationships) that summary statistics miss.

## Practical Work
- Build a visual EDA script that automatically plots distributions and correlation heatmaps for any input DataFrame.

Intermediate
