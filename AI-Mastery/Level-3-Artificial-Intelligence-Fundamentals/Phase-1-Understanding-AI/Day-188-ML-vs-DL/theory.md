# Day 188 Theory: Machine Learning vs Deep Learning

### 1. What Is It?
Classical Machine Learning relies on structured tabular features and domain-engineered attributes using algorithms like Random Forests, SVMs, and XGBoost. Deep Learning uses multi-layer neural networks to learn representations automatically from raw unstructured data.

### 2. Comparison Matrix
| Attribute | Classical Machine Learning | Deep Learning |
|---|---|---|
| **Data Domain** | Structured Tabular Data | Unstructured (Images, Audio, Text, Video) |
| **Feature Engineering** | Manual human feature extraction | Automated end-to-end representation learning |
| **Data Scale Sensitivity** | Performance plateaus at medium data size | Performance scales continuously with massive data |
| **Hardware Requirement** | Standard CPU | High-performance GPUs / TPUs |
| **Training Time** | Seconds to Minutes | Hours to Days / Weeks |

### 3. Summary
Use classical ML (XGBoost) for structured tabular datasets; use Deep Learning for unstructured vision, speech, and text.
