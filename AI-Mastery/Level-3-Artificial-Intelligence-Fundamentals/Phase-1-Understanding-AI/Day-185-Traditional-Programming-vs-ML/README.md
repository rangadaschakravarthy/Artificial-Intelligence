# Day 185 — Traditional Programming vs ML

## Learning Objectives
- Compare Traditional Software Engineering (Software 1.0) with Machine Learning (Software 2.0).
- Analyze structural differences in input, logic, and execution pipelines.
- Identify when to choose traditional programming vs machine learning.

## Prerequisites
- Day 182: Machine Learning

## Topics Covered
- Software 1.0 (Explicit Imperative/Declarative Rules) vs Software 2.0 (Data-Driven Learned Weights)
- Input-Output Flow Diagram Comparison
- Maintenance and Refactoring Tradeoffs: Code maintenance vs Data pipeline maintenance
- Decision Framework: When to write an `if/else` algorithm vs when to train a model

## Difficulty
Beginner / Intermediate
