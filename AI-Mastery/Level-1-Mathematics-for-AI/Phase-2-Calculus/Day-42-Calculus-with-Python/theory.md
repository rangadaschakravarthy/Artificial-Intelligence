# Theory — Calculus with Python

### 1. Simple Definition
Calculus with Python provides three distinct approaches: Symbolic Differentiation (exact formulas with SymPy), Numerical Differentiation (approximate slopes with SciPy), and Automatic Differentiation (exact dynamic gradients with PyTorch).

### 2. Intuition
Symbolic is doing math on paper with formulas. Numerical is measuring slopes on graph paper with a ruler. Automatic differentiation is a smart calculator recording every button press and computing exact slopes backward instantaneously!

### 3. Mathematical Definition
Symbolic: Computes closed-form expression $\frac{d}{dx}[x^3] = 3x^2$.
Numerical: Central difference $\frac{f(x+h) - f(x-h)}{2h} = f'(x) + O(h^2)$.
Automatic Differentiation: Evaluates exact numeric derivatives along dynamic execution graph using dual numbers / elementary chain rule closures.

### 4. Notation
SymPy `sp.diff(f, x)`. SciPy `minimize(f, x0)`. PyTorch `loss.backward()`, `tensor.grad`.

### 5. Formula
$$\text{Gradient Check Error} = \frac{||\mathbf{g}_{autograd} - \mathbf{g}_{numerical}||_2}{||\mathbf{g}_{autograd}||_2 + ||\mathbf{g}_{numerical}||_2} < 10^{-7}$$

### 6. Symbol-by-Symbol Explanation
- $\mathbf{g}_{autograd}$: Gradient vector generated by PyTorch Autograd
- $\mathbf{g}_{numerical}$: Gradient vector generated by Central Difference
- $10^{-7}$: Strict relative error tolerance for gradient correctness

### 7. Step-by-Step Calculation
Compare 3 differentiation methods for $f(x) = x^3 + 2x$ at $x = 2$:
1. Symbolic (SymPy): $f'(x) = 3x^2 + 2 \implies f'(2) = 3(4) + 2 = 14$.
2. Numerical (Central Diff $h=1e-5$): $\frac{(2.00001)^3 + 2(2.00001) - ((1.99999)^3 + 2(1.99999))}{0.00002} = 14.0000000003$.
3. Autograd (PyTorch): `x = torch.tensor(2.0, requires_grad=True); y = x**3 + 2*x; y.backward() -> x.grad = 14.0`.

### 8. Second Example
PyTorch Gradient Reset: PyTorch ACCUMULATES gradients into `.grad` by default (`x.grad += dL/dx`). Always call `optimizer.zero_grad()` before `backward()`!

### 9. Common Mistakes
Forgetting `requires_grad=True` on PyTorch input tensors; failing to call `zero_grad()` causing gradient accumulation bug.

### 10. AI Connection
PyTorch Autograd engine enables arbitrary neural network architectures (Dynamic Graphs, Loops, Conditionals, Transformers) to train automatically without manual calculus derivations.

### 11. Algorithm Connection
PyTorch Autograd, JAX (`jax.grad`), SymPy, SciPy Optimize, TensorFlow GradientTape.

### 12. Practical Interpretation
Automatic Differentiation combines exact precision of Symbolic differentiation with computational efficiency of Numerical differentiation, avoiding expression explosion.

### 13. Interview Insight
Q: 'Compare Symbolic, Numerical, and Automatic Differentiation.' A: Symbolic gives exact mathematical expressions but suffers from expression explosion ($O(2^d)$). Numerical uses finite differences but suffers from truncation error and $O(d)$ speed penalty. Automatic Differentiation computes exact numerical derivatives at machine precision in $O(1)$ backward pass time.

### 14. Summary
Python calculus tools: SymPy for symbolic formulas, SciPy for numerical optimization, and PyTorch Autograd for dynamic automatic differentiation in deep learning.
