# Examples — Functions

## Example 1 — Very Easy
Linear Function: $f(x) = 3x + 2$. Domain $\mathbb{R}$, Range $\mathbb{R}$.

## Example 2 — Beginner
Non-linear Quadratic: $f(x) = x^2$. Domain $\mathbb{R}$, Range $[0, \infty)$.

## Example 3 — Intermediate
Exponential Function: $f(x) = e^x$. Range $(0, \infty)$.

## Example 4 — AI/ML Example
Sigmoid Activation: $\sigma(x) = \frac{1}{1+e^{-x}}$. Bounded Range $(0, 1)$ for probabilities.

## Example 5 — Real-World Interpretation
ReLU Activation: $f(x) = \max(0, x)$. Non-linear, piecewise linear function.
