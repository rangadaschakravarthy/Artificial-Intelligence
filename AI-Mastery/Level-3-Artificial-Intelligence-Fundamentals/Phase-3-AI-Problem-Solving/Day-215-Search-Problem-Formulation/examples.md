# Examples — Day 215: Search Problem Formulation

## Example 1: Basic Grid Representation
State represented as `(x, y)` coordinate tuple in a discrete 2D grid.

## Example 2: Graph Node Representation
State represented as node key in an adjacency list lookup dictionary.

## Example 3: Permutation State Space
8-puzzle tile state represented as integer tuple `(1, 2, 3, 4, 5, 6, 7, 8, 0)`.

## Example 4: Constraint-Based Goal State
Goal evaluated dynamically by constraint function rather than set matching.

## Example 5: Transition Edge Cost Evaluation
Step cost calculated dynamically using Euclidean distance between node coordinates.
