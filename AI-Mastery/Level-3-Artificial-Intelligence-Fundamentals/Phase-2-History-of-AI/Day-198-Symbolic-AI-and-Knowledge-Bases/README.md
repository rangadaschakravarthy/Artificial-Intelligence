# Day 198 — Symbolic AI and Knowledge Bases

## Learning Objectives
- Master the structure of Knowledge-Based Systems (KBS).
- Understand Knowledge Representation languages, Rule Bases, and Fact Bases.
- Learn Forward Chaining and Backward Chaining inference strategies.

## Prerequisites
- Day 181: Symbolic AI

## Topics Covered
- Architecture of a Knowledge-Based System: Fact Base + Rule Base + Inference Engine
- Production Rules format: $	ext{IF } 	ext{Premise} 	ext{ THEN } 	ext{Conclusion}$
- **Forward Chaining**: Data-driven inference (Start with facts $\to$ apply rules $\to$ derive new facts)
- **Backward Chaining**: Goal-driven inference (Start with goal hypothesis $\to$ check supporting rules/facts)
