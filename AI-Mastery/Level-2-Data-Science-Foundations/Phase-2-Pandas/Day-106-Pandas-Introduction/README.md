# Day 106 — Pandas Introduction

## Learning Objectives
- Understand what Pandas is and why it is the premier data manipulation library in Python.
- Learn how Pandas wraps NumPy ndarrays to provide labelled axes, alignment, and tabular structure.
- Understand basic installation, importing conventions, and library architecture.

## Prerequisites
- Phase 1: NumPy (Ndarrays, Data Types, Indexing)

## Topics Covered
1. What is Pandas and history of Python data analysis
2. Relationship between Pandas and NumPy
3. Core Data Structures: Series (1D) and DataFrame (2D)
4. Installing and importing Pandas (`import pandas as pd`)
5. Verifying Pandas environment and versions

## Why This Matters
Pandas is the universal standard tool for tabular data manipulation, cleaning, aggregation, and pre-ML feature preparation.

## Real-World Usage
Reading real-world CSV/Excel datasets, inspecting column data types, handling missing data, and performing data transformations.
