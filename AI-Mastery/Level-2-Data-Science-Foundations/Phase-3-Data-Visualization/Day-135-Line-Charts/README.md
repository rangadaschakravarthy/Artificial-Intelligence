# Day 135 — Line Charts

## Learning Objectives
- Master continuous trend visualization over ordered dimensions (time, sequences).
- Customize line styles, marker symbols, transparency, and confidence bands.
- Plot multiple continuous series on shared and dual y-axes.

## Prerequisites
- Day 134: Matplotlib Basics

## Topics Covered
- When to use Line Charts (continuous trend analysis)
- `ax.plot()` parameters: `color`, `linestyle`, `linewidth`, `marker`, `markersize`, `alpha`
- Plotting multi-line comparison charts
- Shaded uncertainty intervals using `ax.fill_between()`
- Twin Y-Axes plotting using `ax.twinx()`

## Why This Matters
Line charts are the standard tool for financial stock analysis, time-series forecasting, and tracking metrics over time.

## Practical Work
- Plot stock price movements with 95% confidence bands using `fill_between()`.
