# Day 177 — AI Problem Types

## Learning Objectives
- Categorize AI problems into Single-Stage, Sequential Search, Constraint Satisfaction, Adversarial Games, and Probabilistic Learning.
- Match appropriate algorithmic toolkits to specific AI problem classes.

## Prerequisites
- Day 175: Intelligent Agents

## Topics Covered
- Problem Taxonomy:
  - Atomic / Uninformed Search Problems (Route finding, Mazes)
  - Heuristic Informed Search Problems (Pathfinding, A*)
  - Constraint Satisfaction Problems (Sudoku, Map Coloring, Scheduling)
  - Adversarial Search Games (Chess, Tic-Tac-Toe, Go)
  - Knowledge Representation & Logic Reasoning (Expert Systems)
  - Probabilistic Decision Problems (Markov Decision Processes, Reinforcement Learning)
  - Machine Learning & Pattern Recognition (Classification, Regression, Clustering)

## Difficulty
Intermediate
