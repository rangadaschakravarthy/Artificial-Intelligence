# Day 45 — Sample Spaces and Events

## Learning Objectives
- Formalize sample spaces $\Omega$ and event spaces $\mathcal{F}$.
- Master set-theoretic operations on events (Union, Intersection, Complement).
- Understand mutually exclusive and exhaustive events in data science.
- Map machine learning classification outcomes to event spaces.

## Prerequisites
- Day 44 Introduction to Probability.
- Basic Set Theory (Union $\cup$, Intersection $\cap$, Set Difference).

## Topics Covered
1. Sample Space $\Omega$ (Discrete and Continuous)
2. Events as Subsets of Sample Space
3. Set Operations on Events
4. Mutually Exclusive vs Exhaustive Events
5. Event Formulation in Multi-class Machine Learning

## Why This Matters for AI
Every classification problem in machine learning defines a sample space of inputs and targets. Structuring classes as mutually exclusive and exhaustive events ensures that probability outputs are well-defined across all possible outcomes.
