# Day 137 — Histograms

## Learning Objectives
- Analyze continuous variable distributions using `ax.hist()`.
- Choose optimal bin widths, bin counts, and density normalization.
- Overlay Kernel Density Estimates (KDE) and probability density functions.

## Prerequisites
- Day 134: Matplotlib Basics
- Level 1 Statistics: Probability Distributions

## Topics Covered
- Frequency distributions and binning concepts
- `ax.hist()` parameters: `bins`, `density=True`, `cumulative=True`, `alpha`
- Choosing bin counts (Sturges' Rule vs Freedman-Diaconis Rule)
- Overlapping histograms for subgroup comparison
- Overlaying theoretical Gaussian PDF curves

## Why This Matters
Histograms reveal distribution shape, central tendency, variance, modality (bimodal/multimodal), and skewness of continuous features.

## Practical Work
- Plot a normalized histogram overlaid with a normal distribution PDF curve.
