# Examples — Scalars and Vectors

## Example 1 — Very Easy
Scalar: Price $p = 99.99$. Vector: 2D coordinates $[x, y]^T = [5, -2]^T$.

## Example 2 — Beginner
Converting tabular row to vector: Patient (age=45, blood_pressure=120, cholesterol=200) $\rightarrow \mathbf{x} = [45, 120, 200]^T$.

## Example 3 — Intermediate
3D Geometric Vector: $\mathbf{u} = [1, 2, 3]^T$. Arrow from origin $(0,0,0)$ to point $(1,2,3)$.

## Example 4 — AI/ML Example
Word Embedding: Word 'king' represented as 4D vector $[0.25, -0.11, 0.88, 0.05]^T$.

## Example 5 — Real-World Interpretation
Image Pixel Column: A 3-pixel RGB column represented as $[255, 0, 128]^T$.
