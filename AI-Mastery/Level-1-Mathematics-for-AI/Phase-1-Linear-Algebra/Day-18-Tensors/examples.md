# Examples — Tensors

## Example 1 — Very Easy
0D Tensor: Scalar loss $L = 0.245$, shape `()`, rank 0.

## Example 2 — Beginner
1D Tensor: Bias vector `[0.5, -0.2, 0.1]`, shape `(3,)`, rank 1.

## Example 3 — Intermediate
2D Tensor: Weight matrix, shape `(128, 784)`, rank 2.

## Example 4 — AI/ML Example
3D Tensor: NLP Sentence batch (16 sentences, 50 words, 768 embedding dim) $\implies$ shape `(16, 50, 768)`, rank 3.

## Example 5 — Real-World Interpretation
4D Tensor: Image mini-batch (64 images, 3 channels, 224x224 pixels) $\implies$ shape `(64, 3, 224, 224)`, rank 4.
