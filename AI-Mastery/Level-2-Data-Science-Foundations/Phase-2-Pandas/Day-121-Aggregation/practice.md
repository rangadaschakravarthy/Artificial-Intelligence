# Day 121 Practice Questions: Aggregation

## Level 1 — Basic
1. What argument formats does `.agg()` accept?
2. How do you pass multiple built-in aggregation functions to a single column?
3. What is Named Aggregation syntax in Pandas?
4. True or False: `.agg()` can only be called on a `GroupBy` object, not directly on a `DataFrame`.
5. What built-in aggregation calculates standard deviation?

## Level 2 — Coding
1. Group `df` by `'Category'` and calculate `min`, `max`, and `median` for `'Price'`.
2. Group `df` by `'Department'` and apply total sum to `'Sales'` and average to `'Rating'`.
3. Perform named aggregation on `df` grouped by `'City'` to calculate `Total_Rev = ('Revenue', 'sum')` and `Avg_Discount = ('Discount', 'mean')`.
4. Use a custom lambda function inside `.agg()` to compute the range (`max - min`) of `'Temperature'` per `'City'`.
5. Flatten a MultiIndex column DataFrame generated by `.agg()`.

## Level 3 — Data Analysis
1. Calculate average, total, and count of sales for each retail branch.
2. Group customer service tickets by agent and calculate mean resolution time and total tickets handled.
3. Analyze credit risk by calculating default rate (mean) and total loan count per credit score tier.
4. Calculate 25th and 75th percentiles of transaction values per country.
5. Compute total revenue and revenue standard deviation per product category.

## Level 4 — Debugging
1. Fix syntax error: `df.groupby('Dept').agg({'Sales': 'sum', 'mean'})`.
2. Fix output issues where column names become nested MultiIndex tuples like `('Sales', 'sum')`.
3. Correct custom lambda error: `df.groupby('Cat')['Val'].agg(lambda x: x.max - x.min)`.

## Level 5 — AI/ML Application

2. How can aggregation metrics be used to detect anomaly outliers in grouped sensor logs?
