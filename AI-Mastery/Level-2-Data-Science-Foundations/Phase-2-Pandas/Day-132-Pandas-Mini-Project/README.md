# Day 132 — Pandas Mini Project: Real-World Dataset Cleaning and Analysis

## Learning Objectives
- Execute a comprehensive, multi-step Data Science project using Pandas.
- Load, inspect, clean, analyze, reshape, and prepare a messy e-commerce customer transaction dataset.
- Generate business insights and export an ML-ready dataset.

## Prerequisites
- Days 106–131 (Phase 2 Pandas Complete)

## Topics Covered
- Dataset loading and preliminary audit
- Advanced string cleaning and numeric type conversion
- Handling missing data and deduplication policy
- GroupBy, Aggregation, and Pivot Table business reporting
- Time series extraction and monthly revenue trend analysis
- Categorical one-hot encoding and feature scaling
- Validating and exporting ML-ready features $X$ and target $y$

## Why This Matters
This capstone mini-project consolidates all Phase 2 skills into a realistic end-to-end Data Science workflow.

## Real-World Usage
Simulating an enterprise Data Analyst / Data Scientist workflow processing raw dirty client transaction dumps into executive reports and ML features.

## Study Order
1. Read `theory.md` for project architecture.
2. Study `examples.md` for workflow execution.
3. Run `code.py` to execute the full mini-project.
4. Complete `practice.md` and verify with `solution.md`.

## Practical Work
