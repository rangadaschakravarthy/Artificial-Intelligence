# Machine Learning Mastery Checklist

## Core Concepts & Fundamentals
- [ ] I can explain Machine Learning and contrast it with traditional software engineering.
- [ ] I can define sample count $n$, feature dimension $d$, feature matrix $X$, and target vector $y$.
- [ ] I understand train, validation, and test dataset splitting strategies.
- [ ] I can explain the difference between learned parameters ($\mathbf{w}, b$) and hyperparameters ($\alpha$).
- [ ] I can explain the Bias-Variance Tradeoff, Overfitting, and Underfitting.

## Supervised Learning
- [ ] I can implement Simple & Multiple Linear Regression using OLS Normal Equation $(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$.
- [ ] I can explain Loss Functions (MAE, MSE, RMSE, $R^2$) and their outlier sensitivities.
- [ ] I understand Gradient Descent optimization (Batch, Stochastic, Mini-batch).
- [ ] I can explain Ridge ($L_2$) and Lasso ($L_1$) regularization and why feature scaling is required.
- [ ] I can implement Logistic Regression and derive the Sigmoid function.
- [ ] I can construct and interpret a Confusion Matrix, Precision, Recall, F1, and ROC-AUC.
- [ ] I can implement $k$-Nearest Neighbors ($k$-NN) and explain the Curse of Dimensionality.
- [ ] I can explain Decision Trees (Entropy, Gini Impurity) and Random Forest Ensemble Bagging.
- [ ] I understand Naive Bayes and Support Vector Machines (Hyperplanes & Kernel Trick).

## Unsupervised & Advanced Learning
- [ ] I can implement K-Means clustering and select optimal $K$ via Elbow & Silhouette metrics.
- [ ] I understand Hierarchical Agglomerative Clustering and DBSCAN density clustering.
- [ ] I can implement Principal Component Analysis (PCA) via covariance eigen-decomposition.
- [ ] I can explain t-SNE and UMAP manifold visualization.
- [ ] I can compute Support, Confidence, and Lift for Association Rule Learning (Apriori).
- [ ] I can contrast Supervised, Unsupervised, Semi-Supervised, and Self-Supervised Learning.
- [ ] I can explain Reinforcement Learning (Agent, State, Action, Reward, MDP, Q-Learning).

## Workflow & MLOps
- [ ] I can build scikit-learn `Pipeline` and `ColumnTransformer` objects to prevent Data Leakage.
- [ ] I can perform $K$-Fold Cross-Validation and Hyperparameter Tuning via `GridSearchCV`.
- [ ] I can diagnose high bias vs high variance using Learning Curves.
- [ ] I can extract model explainability via Permutation Feature Importance and SHAP.
- [ ] I can build complete end-to-end Machine Learning capstone projects.
