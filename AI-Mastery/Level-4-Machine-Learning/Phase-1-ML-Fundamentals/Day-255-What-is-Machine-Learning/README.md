# Day 255 — What Is Machine Learning?

## Learning Objectives
- Define Machine Learning (ML) from computer science, statistical, and engineering perspectives.
- Contrast Traditional Rule-Based Programming with Machine Learning.
- Understand how algorithms learn patterns directly from empirical data.

## Prerequisites
- Level 1: Mathematics for AI (Linear Algebra, Calculus, Probability, Statistics).
- Level 2: Data Science Foundations (NumPy, Pandas, EDA).
- Level 3: AI Fundamentals (Intelligent Agents & Problem Solving).

## Topics Covered
1. Classical vs. ML Paradigm Shift
2. Arthur Samuel and Tom Mitchell Definitions of ML
3. Rules vs. Learned Patterns
4. When to Use ML (and When NOT to Use ML)

## Why This Matters
Machine Learning shifts software development from hand-crafting complex conditional logic to training algorithms on data to generalize predictions.

## Connection to Previous Levels
- **Level 1 Math**: Optimization of parameters via loss functions.
- **Level 2 Data Science**: Structuring raw data matrices ($X, y$) for algorithm ingestion.
- **Level 3 AI**: Machine Learning is the data-driven branch of Artificial Intelligence.

## What You Will Build/Practice
- Build a Python script contrasting rule-based decision trees with a scikit-learn ML model.
- Solve 20+ structured practice problems.

## Key Concepts
- Data-driven learning, Training signal, Inductive bias, Generalization.

## Interview Relevance
"What is Machine Learning and how does it differ from traditional software engineering?" is a standard opening interview question.

## Difficulty
Beginner

## Completion Checklist
- [ ] I can explain the concept of ML without memorizing a definition.
- [ ] I can contrast $Input + Rules \to Output$ with $Input + Output \to Model$.
- [ ] I can implement both a rule-based logic and an ML model in Python.
- [ ] I can explain where ML is used in industry.
- [ ] I can answer common interview questions on ML foundations.
