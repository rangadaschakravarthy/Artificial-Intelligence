# Day 183 — Deep Learning

## Learning Objectives
- Understand Deep Learning as a specialized subfield of Machine Learning based on artificial neural networks.
- Learn representation learning and hierarchical feature extraction.
- Contrast manual feature engineering with end-to-end deep learning.

## Prerequisites
- Day 182: Machine Learning

## Topics Covered
- Deep Learning Definition (Multi-layer Artificial Neural Networks - ANNs)
- Representation Learning: Automatic hierarchical feature extraction (Low-level edges -> Mid-level textures -> High-level semantic objects)
- Drivers of the Deep Learning Revolution: Massive Datasets (Big Data), Hardware (GPUs/TPUs), Algorithmic Innovations (ReLU, Backprop)
- Core Architectures: Feedforward (MLP), Convolutional (CNN), Recurrent (RNN), Transformers
- When Deep Learning excels vs when classical ML (Random Forests) is preferred
