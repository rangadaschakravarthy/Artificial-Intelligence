# Day 147 — Plotly Introduction

## Learning Objectives
- Understand Plotly's interactive graph architecture.
- Build interactive scatter, line, and bar charts using `plotly.express` (`px`).
- Export interactive charts to standalone HTML files.

## Prerequisites
- Day 133: Introduction to Data Visualization

## Topics Covered
- Plotly Express (`px`) vs Plotly Graph Objects (`go`)
- Interactive features: Hover tooltips, panning, zooming, legend filtering
- Basic express plots: `px.scatter()`, `px.line()`, `px.bar()`, `px.histogram()`
- Customizing hover data using `hover_data` parameter
- Exporting interactive figures with `fig.write_html()`

## Why This Matters
Interactive plots allow stakeholders to explore data values dynamically without re-running code.

## Practical Work
- Generate an interactive Plotly scatter plot with custom hover tooltips and export to HTML.
