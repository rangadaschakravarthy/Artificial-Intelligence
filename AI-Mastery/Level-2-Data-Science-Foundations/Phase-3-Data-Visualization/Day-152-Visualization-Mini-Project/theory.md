# Day 152 Theory: Visualization Mini Project Architecture

### 1. What Is It?
The Visualization Mini Project is a capstone workflow that turns raw tabular data into a suite of explanatory static graphics and interactive web charts.

### 2. Project Stages
1. **Univariate Audit**: Plot histograms and countplots for all features.
2. **Bivariate Inspection**: Plot scatter plots and boxplots against target metrics.
3. **Correlation Analysis**: Build a masked heatmap of numeric features.
4. **Narrative Refinement**: Format charts with action headers, despining, and strategic accent colors.
5. **Interactive Export**: Generate an interactive Plotly HTML dashboard.

### 3. Summary
This project consolidates all Phase 3 visualization tools into a unified exploratory analytical portfolio artifact.
