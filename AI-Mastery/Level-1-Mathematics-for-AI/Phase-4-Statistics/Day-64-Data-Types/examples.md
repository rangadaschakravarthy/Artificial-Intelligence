# Day 64 Worked Examples: Data Types

## Example 1: Nominal — Car Brands
Brands: [Toyota, Ford, Honda]. Operations: Mode, Count.

## Example 2: Ordinal — Customer Satisfaction
Ratings: [Poor, Fair, Good, Excellent]. Operations: Median, Mode, Order comparison.

## Example 3: Interval — Dates & Temperature
Years: 2020, 2024. Difference = 4 years. Ratio 2024/2020 has no physical meaning.

## Example 4: Ratio — Model Latency
Latencies: 10ms vs 20ms. 20ms is twice as slow as 10ms (True zero exists).

## Example 5: Real-World AI — Pipeline Preprocessing
Pipeline: Nominal -> OneHotEncoder; Ratio -> StandardScaler; Ordinal -> OrdinalEncoder.
