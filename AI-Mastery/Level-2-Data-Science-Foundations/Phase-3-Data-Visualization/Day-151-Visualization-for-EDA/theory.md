# Day 151 Theory: Visualization for EDA

### 1. What Is It?
Visualization for EDA uses fast diagnostic graphics to explore dataset structure, inspect feature interactions, and detect anomalies.

### 2. Diagnostic Steps
1. **Missing Data Inspection**: Visualizing missingness matrices.
2. **Univariate Distributions**: Histograms and KDE plots for all numeric features.
3. **Bivariate Relationships**: Scatter plots and pair plots for feature-target pairs.
4. **Correlation Matrix**: Heatmap of feature correlations.

### 3. Summary
Visual EDA provides automated graphical diagnostics to uncover data quality flaws and structural feature patterns.
