# Day 44 — Introduction to Probability

## Learning Objectives
- Master the fundamental concept of probability as a measure of likelihood $[0, 1]$.
- Understand deterministic vs probabilistic systems in AI and Machine Learning.
- Learn empirical, theoretical, and subjective definitions of probability.
- Apply basic probability principles to machine learning models and uncertainty estimation.

## Prerequisites
- High school algebra and set notation.
- Day 1-25 Linear Algebra foundations.

## Topics Covered
1. Deterministic vs Stochastic Systems in AI
2. Mathematical Definition of Probability
3. Kolmogorov Axioms of Probability
4. Frequentist vs Bayesian Perspectives
5. Probability in Machine Learning (Logits, Softmax, Confidence Scores)

## Why This Matters for AI
Machine learning algorithms deal with real-world noisy data, imperfect sensors, and missing variables. Probability provides the mathematical language to quantify uncertainty, make optimal decisions under risk, and turn raw neural network outputs into calibrated probabilities.
