# Examples — Linear Algebra for Machine Learning

## Example 1 — Very Easy
Linear Regression: $y = \mathbf{w}^T \mathbf{x} + b$ computes scalar prediction via vector dot product.

## Example 2 — Beginner
Logistic Regression: $P(y=1|x) = \sigma(\mathbf{w}^T \mathbf{x} + b)$ applies sigmoid function to dot product.

## Example 3 — Intermediate
SVM Margin: Distance to hyperplane measured by L2 norm $2 / ||\mathbf{w}||_2$.

## Example 4 — AI/ML Example
Deep Neural Net Layer 1: $\mathbf{H}_1 = \text{ReLU}(\mathbf{X} \mathbf{W}_1 + \mathbf{b}_1)$. Layer 2: $\mathbf{Y} = \mathbf{H}_1 \mathbf{W}_2 + \mathbf{b}_2$.

## Example 5 — Real-World Interpretation
Cosine Similarity RAG Search: Finding top $k$ relevant documents via normalized embedding dot products.
