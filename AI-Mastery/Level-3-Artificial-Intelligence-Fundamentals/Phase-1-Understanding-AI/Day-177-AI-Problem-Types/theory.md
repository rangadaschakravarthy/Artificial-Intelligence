# Day 177 Theory: AI Problem Types

### 1. What Is It?
AI Problem Types classify real-world tasks based on their state space properties, observability, action interactions, and objective structures.

### 2. AI Problem Taxonomy Table
| Problem Type | Characteristics | Classic Examples | Primary Algorithms |
|---|---|---|---|
| **Classical Search** | Deterministic, fully observable, single-agent | 8-Puzzle, Maze Routing | BFS, DFS, A* |
| **Constraint Satisfaction** | Discrete variables with hard constraints | Sudoku, Class Scheduling | Backtracking, Constraint Propagation |
| **Adversarial Games** | Two-player, zero-sum, competitive | Chess, Checkers | Minimax, Alpha-Beta Pruning |
| **Knowledge & Reasoning** | Formal logical syllogisms, rules | Medical expert rule base | Forward/Backward Chaining |
| **Probabilistic Learning** | High-dimensional data, patterns | Image recognition, Churn | Neural Networks, Random Forests |

### 3. Summary
Matching an AI task to its formal problem type identifies the optimal algorithmic solution paradigm.
