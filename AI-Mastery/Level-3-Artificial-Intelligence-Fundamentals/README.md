# Level 3 — Artificial Intelligence Fundamentals

Welcome to **Level 3 of the AI-Mastery Curriculum**! This repository builds a rigorous, beginner-friendly conceptual and practical foundation in classical and modern Artificial Intelligence.

## Curriculum Structure & Phases

### Phase 1 — Understanding AI (Days 173–192)
- Introduction to AI, Intelligent Agents, Rationality, AI vs ML vs DL vs Generative AI, AGI, Symbolic AI, and System Architecture.

### Phase 2 — History of AI (Days 193–209)
- Historical progression from Turing Test (1950), Dartmouth Conference, Expert Systems, AI Winters, Statistical AI, to Deep Learning and Transformers.

### Phase 3 — AI Problem Solving (Days 210–225)
- State spaces, problem formulation $\langle S, s_0, A, T, G, c \rangle$, search trees vs graphs, knowledge representation, reasoning, and decision making under uncertainty.

### Phase 4 — Search Algorithms (Days 226–243)
- Deep, hands-on treatment of Breadth-First Search (BFS), Depth-First Search (DFS), Uniform Cost Search (UCS), Greedy Best-First Search, Heuristics ($h(n)$, admissibility, consistency), and $A^*$ Search.

### Phase 5 — Adversarial Search (Days 244–254)
- Game trees, MAX/MIN players, zero-sum games, Minimax recursion, Alpha-Beta pruning ($\alpha \ge \beta$), and game-playing AI engines.
