# Day 175 — Intelligent Agents

## Learning Objectives
- Master the Intelligent Agent paradigm: Agents, Environments, Sensors, and Actuators.
- Understand PEAS (Performance, Environment, Actuators, Sensors) descriptions.
- Classify environments (Fully vs Partially Observable, Deterministic vs Stochastic, Static vs Dynamic, Discrete vs Continuous).

## Prerequisites
- Day 173: Introduction to AI

## Topics Covered
- Anatomy of an Agent: Percepts, Sensors, Architecture, Agent Program, Actuators, Actions
- PEAS Framework for AI System Specification
- Environment Properties:
  - Fully Observable vs Partially Observable
  - Single-agent vs Multi-agent
  - Deterministic vs Stochastic / Nondeterministic
  - Episodic vs Sequential
  - Static vs Dynamic vs Semidynamic
  - Discrete vs Continuous
  - Known vs Unknown
- Agent Types: Simple Reflex, Model-Based Reflex, Goal-Based, Utility-Based, Learning Agents

## Completion Checklist
- [ ] I can write PEAS specifications for any AI problem domain.
- [ ] I can classify environments across all 7 environmental dimensions.
- [ ] I understand the 5 core agent program architectures.
