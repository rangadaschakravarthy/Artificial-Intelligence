# Day 194 Theory: Turing and Computation

### 1. What Is It?
Alan Turing established the theoretical foundations of modern computer science and AI by formalizing computation using the Universal Turing Machine model and asking whether machines can think.

### 2. Universal Turing Machine Model
A Turing Machine consists of:
1. An **infinite tape** divided into cells storing symbols.
2. A **read/write head** moving left or right over the tape.
3. A **state register** tracking current machine state.
4. A **finite transition table** defining action rules based on current state and scanned symbol.

### 3. Significance for AI
Turing proved that a single Universal Machine could simulate *any* algorithmic procedure, establishing that physical hardware is separate from software logic—enabling artificial intelligence programs.

### 4. Summary
Turing formalized universal computation, proving that algorithms can be executed by symbol-manipulating machines.
