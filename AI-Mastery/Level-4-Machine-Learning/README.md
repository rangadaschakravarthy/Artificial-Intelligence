# Level 4 — Machine Learning

Welcome to **Level 4 of the AI-Mastery Curriculum**! This repository builds a complete, beginner-to-strong-intermediate Machine Learning course covering theory, mathematical derivations, scratch NumPy algorithms, scikit-learn engineering, and capstone projects.

## Curriculum Structure & Phases

### Phase 1 — ML Fundamentals (Days 255–263)
- What is ML, ML Terminology, Feature Matrix $X$ & Target $y$, Train/Val/Test Splits, Parameters vs Hyperparameters, Model Capacity, Prediction vs Inference, Generalization (Bias-Variance), and the Complete ML Workflow.

### Phase 2 — Types of Machine Learning (Days 264–268)
- Foundations of Supervised, Unsupervised, Semi-Supervised, Self-Supervised, and Reinforcement Learning.

### Phase 3 — Supervised Learning (Days 269–284)
- **Section A (Regression)**: Simple & Multiple Linear Regression, OLS Normal Equation, MAE/MSE/RMSE/$R^2$, Gradient Descent, Ridge ($L_2$), Lasso ($L_1$), ElasticNet.
- **Section B (Classification)**: Logistic Regression (Sigmoid $\sigma(z)$), Confusion Matrix, Precision/Recall/F1/ROC-AUC, $k$-NN, Decision Trees, Random Forests, Naive Bayes, Support Vector Machines (SVM & Kernel Trick).
- **Section C**: Supervised Learning Algorithm Comparison Matrix.

### Phase 4 — Unsupervised Learning (Days 285–293)
- **Section A (Clustering)**: K-Means, Elbow Method & Silhouette Score, Hierarchical Agglomerative Clustering, DBSCAN.
- **Section B (Dimensionality Reduction)**: PCA (Covariance Eigen-Decomposition), t-SNE & UMAP.
- **Section C (Association)**: Apriori algorithm, Support, Confidence, Lift.

### Phase 5 — Semi-Supervised and Self-Supervised Learning (Days 294–296)
- Pseudo-Labeling, Label Propagation, Pretext tasks, Contrastive learning (SimCLR), Foundation model pre-training.

### Phase 6 — Reinforcement Learning Foundations (Days 297–301)
- Agent-environment loop, Rewards & Discounted Returns $G_t$, Exploration vs Exploitation ($\epsilon$-greedy), Markov Decision Processes (MDP), Q-Learning Bellman updates.

### Phase 7 — ML Workflow & Pipelines (Days 302–307)
- Dataset Preparation & EDA, scikit-learn `Pipeline` & `ColumnTransformer`, $K$-Fold Cross-Validation, `GridSearchCV` Hyperparameter Tuning, Learning Curves, End-to-End MLOps Pipeline.

### Phase 8 — Model Interpretation (Day 308)
- Feature Importances, Permutation Importance, SHAP/LIME explainability concepts.
