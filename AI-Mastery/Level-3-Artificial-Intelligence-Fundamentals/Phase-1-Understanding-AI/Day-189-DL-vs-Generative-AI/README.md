# Day 189 — DL vs Generative AI

## Learning Objectives
- Clarify the relationship between Deep Learning foundational architectures and Generative AI capability applications.
- Contrast Discriminative Deep Learning (CNN classification, ResNet) with Generative AI (LLMs, Diffusion Models).

## Prerequisites
- Day 183: Deep Learning
- Day 184: Generative AI

## Topics Covered
- Relationship: Generative AI is a functional capability area powered primarily by Deep Learning architectures
- Discriminative DL ($P(Y \mid X)$) vs Generative AI ($P(X)$)
- Deep Learning Foundation Models (Transformers, Diffusion) as the engine driving GenAI
- Multimodal foundation architectures
