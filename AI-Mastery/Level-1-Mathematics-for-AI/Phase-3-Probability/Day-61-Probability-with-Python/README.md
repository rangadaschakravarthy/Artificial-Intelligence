# Day 61 — Probability with Python

## Learning Objectives
- Master Python libraries for probability (`numpy.random`, `scipy.stats`).
- Perform Monte Carlo simulations for complex probabilistic problems.
- Implement random variable sampling and fitting distributions to empirical data.
- Build interactive probability tools in Python.

## Prerequisites
- Days 44–60 Probability curriculum.
- Core Python and NumPy proficiency.

## Topics Covered
1. NumPy Random Module (`np.random.Generator`)
2. SciPy Statistical Distributions (`scipy.stats`)
3. Monte Carlo Simulation Techniques
4. Fitting Distributions to Real Data (`scipy.stats.fit`)
5. Random Sampling and Bootstrapping

## Why This Matters for AI
Modern AI relies on probabilistic programming (PyMC, NumPyro), random sampling (Monte Carlo Tree Search, Diffusion sampling), and statistical distribution fitting.
