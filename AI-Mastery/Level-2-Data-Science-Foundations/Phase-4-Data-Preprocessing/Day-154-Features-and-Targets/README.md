# Day 154 — Features and Targets

## Learning Objectives
- Formulate input feature space matrices ($X$) and target prediction vectors ($y$).
- Distinguish between supervised targets (Regression vs Classification) and unsupervised representations.
- Identify continuous, discrete, ordinal, and nominal feature types.
