# Day 188 — ML vs DL

## Learning Objectives
- Differentiate Classical Machine Learning from Deep Learning.
- Evaluate dataset size, hardware requirements, and feature engineering differences.
- Select between Random Forests / XGBoost vs Neural Networks for structured tabular vs unstructured data.

## Prerequisites
- Day 182: Machine Learning
- Day 183: Deep Learning

## Topics Covered
- Subset Hierarchy: $	ext{DL} \subset 	ext{ML} \subset 	ext{AI}$
- Feature Engineering: Manual (Classical ML) vs Automated Representation Learning (DL)
- Data Performance Scale Curve: How DL accuracy continues scaling with Big Data where classical ML plateaus
- Tabular Data Dominance: Why XGBoost often beats Neural Networks on structured tabular DataFrames
