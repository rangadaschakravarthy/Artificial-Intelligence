- Understand element-wise (Hadamard) operations
- Visualize vector addition geometrically using the parallelogram rule

## Topics Covered
- Vector Addition and Subtraction
- Scalar Multiplication properties
- Element-wise (Hadamard) Product
- Linear Combinations of vectors
- Geometric Interpretation (Parallelogram law)

## Why This Matters for AI
Neural networks combine feature vectors linearly ($w_1 x_1 + w_2 x_2 + \dots$) and apply element-wise activation functions. Understanding vector arithmetic is fundamental to model propagation.
