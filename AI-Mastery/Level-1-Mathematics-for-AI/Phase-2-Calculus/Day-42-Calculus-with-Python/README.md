# Day 42 — Calculus with Python

## Learning Objectives
- Master Python tools for Symbolic, Numerical, and Automatic Differentiation
- Use SymPy for exact symbolic calculus derivatives, limits, and integrals
- Use SciPy `scipy.optimize` for numerical minimization
- Use PyTorch `torch.autograd` for Automatic Differentiation and computational graphs

## Prerequisites
Days 26-41 Calculus Phase

## Topics Covered
- Symbolic Differentiation (SymPy `diff`, `limit`, `integrate`)
- Numerical Differentiation (SciPy `scipy.optimize.minimize`)
- Automatic Differentiation (PyTorch `autograd.grad`, `loss.backward()`)
- Computational graphs and `.grad` tracking in PyTorch
- Gradient checking (comparing autograd vs central differences)

## Why This Matters for AI
PyTorch's automatic differentiation engine (`autograd`) eliminates the need to manually derive gradients for complex neural architectures, enabling rapid AI model prototyping.
